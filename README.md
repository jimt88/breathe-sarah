# Breathe, Sarah

A calm breathing app and birthday gift for Sarah, from Jim & Sem.

## Install on your phone

1. Open the link once while you're online.
2. **iPhone:** in Safari, tap Share, then **Add to Home Screen**.
   **Android:** in Chrome, tap ⋮, then **Install app** or **Add to Home screen**.
3. Open it from the new icon. After that first visit it works offline.

Changes pushed to this repo reach the app the next time it's opened with a connection.
